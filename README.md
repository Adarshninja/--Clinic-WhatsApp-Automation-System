# 🏥 Clinic WhatsApp Automation System

A web-based system to help clinics manage patient inquiries and leads received through WhatsApp in a structured and efficient way.

Built to solve a real-world problem: delayed replies, missed messages, and unorganized communication.

---

## 📌 Problem

Many small clinics handle patient communication manually on WhatsApp.

This often leads to:

- Missed inquiries  
- Late responses  
- Lost leads  
- No proper record system  

Which affects both patient experience and clinic efficiency.

---

## 💡 Solution

This project provides a centralized dashboard where clinics can:

✅ Track WhatsApp inquiries  
✅ Manage patient leads  
✅ Export and delete records  
✅ Monitor conversations  
✅ Stay organized  

All in one simple interface.

---

## 🚀 Features

- 📊 Admin Dashboard  
- 📱 WhatsApp Lead Management  
- 📁 Export Data (CSV)  
- 🗑️ Delete & Update Records  
- 🌗 Light/Dark Mode UI  
- ⚡ Fast Backend APIs  

---
